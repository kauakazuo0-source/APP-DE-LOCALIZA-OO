# FastLocation & Cliente MQTT Duplo — Hub Web Interativo

Aplicação web modular em Vite, JavaScript ES Modules e Tailwind CSS, com dois módulos:

- **FastLocation**: consulta de CEP/endereço, cache local, histórico, mapas e rotas.
- **Cliente MQTT Duplo**: Publisher e Subscriber via WebSocket MQTT, JSON e tópicos.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite (por padrão http://localhost:5173).

## Tecnologias
Vite 6, Tailwind CSS v4, Leaflet, MQTT.js v5, ViaCEP, Nominatim, Photon e OSRM.
